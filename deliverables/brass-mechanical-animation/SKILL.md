# 黄铜机械动画

将用户提供的概念映射成可读的机构、动作和镜头，最终交付可播放 MP4 与可修改工程。随包提供已存在的 V4 场景，不依赖其他技能、付费 API、原作者磁盘目录或在线三维素材。版本为 1.0.0。

## 先选择任务

- **原样复刻**：先读 [复刻步骤](references/reproduce.md)，用初始化脚本复制模板，在新目录安装依赖、预览、导出。无需重新设计现有机构。
- **换主题或改镜头**：再读 [场景与时间轴](references/scene-guide.md)，先建立「概念 → 机构 → 输入/动作/输出」映射，沿用同一载体贯穿各站的叙事。
- **追求更精致或修复观感**：按需读 [美术与工艺](references/art-direction.md)，从几何装配、材料、动作摄影、编码分层定位问题。

先检查 [参考成片](assets/reference/eighteenth-century-sample.mp4) 和 [最终解码图](assets/reference/final-decoded-18.4.png)，明确基线来自已交付样片；不要把技能说明当成已经看过的影片。

## 工作流程

1. 从用户要求确定主题、时长、画幅、声音和是否保留文字。信息不足时，复刻默认采用随包的 24 秒、1920×1080、30fps、纯机械画面与轻量拟音；明确用户要求优先。没有要求加旁白、音乐或网页界面时不自行添加。
2. 新项目用 `node <skill目录>/scripts/init-project.cjs <新工程目录>` 创建独立工程。初始化器拒绝覆盖已有路径。修改工程副本，不直接改安装目录里的模板。
3. 工程内先运行 `npm ci`、`npm run browser:install`，再运行 `npm run smoke` 验证渲染、编码、声音与解码。先读复刻文档，确认环境需要联网下载哪些依赖。
4. 新题材先把关键机构及一次完整动作做好，检查最近景、接触和复位，再扩成相连系统。随包已有完整机构时可直接修改；需要更长影片时扩写事件与镜头，不仅放慢同一段。
5. 运行 `npm run preview` 查看最终分辨率的源帧，结合动作前、接触中、结果后的连续画面检查；按 [验收说明](references/verification.md) 区分技术结果、实际观感与未核实项。
6. 运行 `npm run render` 导出有声 `output/film.mp4`，保留静音片、源代码、QA 图和验证 JSON。浏览器 HTML 是内部渲染入口，用户要视频时必须交付实际 MP4。
7. 默认直接交用户反馈，不引入独立审片代理或逐阶段确认。只有真正看过、听过的范围才可记录为视听检查；完整解码不等于审美认可。

## 本风格的关键约束

- 黄铜曲面、钢制摩擦面、深色木座与少量象牙色工作件有明确层级；薄座、纤细支承、开放轮系和少量雕饰共同成立，不能只改成金色。
- 近景能说明零件如何支承、连接和运动。重复螺钉数量不代表机械完成度；轴套、导轨、轮系与工作包络必须读得清楚。
- 夹持、比较、压印的动作有因果，工作件身份连续。相机位置和注视目标独立变化，在关键接触处停留，最后揭示系统。
- `window.renderAt(seconds)` 必须可按任意时间重入，状态由时间直接计算，不依赖上一次调用、真实时钟、帧间累加或未设种子的随机数。
- 该场景是十八世纪科学仪器语言启发的解释性装置。业务机构、传动和测量不构成历史复原、工程可制造性或物理仿真的证据。
